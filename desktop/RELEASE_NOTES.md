Faithful Keys is now available as a downloadable desktop app.

| Computer | Download |
| --- | --- |
| Windows 64-bit PC | File ending in `win-x64.exe` |
| Mac with Apple silicon (M1 or newer) | File ending in `mac-arm64.dmg` |
| Mac with an Intel processor | File ending in `mac-x64.dmg` |

On Mac, open the disk image and drag Faithful Keys into Applications.
On Windows, run the installer. It installs for your user without administrator access.

Includes the current Faithful Keys interface, Guided and Explore modes, ear
training, progression tools, USB/OS-exposed Bluetooth MIDI, saved local progress,
and bundled fonts and sounds for offline practice. Cloud song features and
YouTube still need internet access. Desktop progress is separate from browser
progress; it persists between desktop launches and upgrades.

These free builds have **no paid publisher certificate or Apple notarization**.
Mac and Windows may show a security prompt. Only approve the official download
if you trust it and your computer's policy permits unsigned applications.
Mac builds carry a local ad-hoc signature, which does not verify a publisher.

USB and Bluetooth MIDI depend on the connected device and OS drivers. Bluetooth
audio pairing alone is not Bluetooth MIDI. Physical keyboard latency and pairing
must be checked with your hardware; packaging does not guarantee lower latency.

Use Help → Desktop guide for setup, or Help → Check for updates for newer releases.
SHA-256 checksum files and native platform verification reports accompany the downloads.
