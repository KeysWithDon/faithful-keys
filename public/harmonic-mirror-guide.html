A visual language for the keyboard

Four diagrams. Four questions.

Harmonic Mirror displays one diagram at a time. Each uses a different geometric system to explain a different relationship in your actual playing. These shapes are based on notes, not decorative animations.

Diagram 01

Chord Shapes — What collection am I playing?

Every sounding pitch class becomes a vertex at a fixed position on a twelve-point chromatic circle. Consecutive active pitches connect to make the perimeter. Triads form triangles, seventh chords make quadrilaterals, and richer collections can make pentagons or hexagons. The edges reveal the chromatic spacing between tones.

C major · Triangle

Three tones; an unequal-sided pattern because the chromatic gaps are 4, 3 and 5.

C diminished 7 · Square

Four equally spaced tones: C, E♭, G♭, A (enharmonically B𝄫).

Cmaj9 · Pentagon

Five unique tones produce five corners. Revoicing does not change the pitch-class outline.

Whole-tone collection · Hexagon

Six equally spaced tones make a regular hexagon. This collection need not be one named chord.

The shape is independent of octave or inversion: doubling a C in another octave does not introduce a new corner. Gold indicates a recognized root, teal other core tones, and violet extensions. A complex cluster can have an accurate geometric outline even when it has no single recognized chord name.

Diagram 02

Interval Rays — How are the tones spaced?

The hub is the chord root, or the lowest sounding note if the root is unclear. Rays point to each distinct pitch class. Labels count upward semitones from the hub, modulo twelve.

The spoke length is a graphic convention; octave registers are still tracked in MIDI but folded into one chromatic position here.

Diagram 03

Voice Movement — What actually changed?

Two separate columns represent previous and current MIDI pitches. Horizontal teal connections are exactly held notes. Sloped gold lines are estimated nearest-note movements with semitone values, using the actual octaves played.

These links are an estimate, not a definitive arrangement of musical voices. Crossings and complex chords can have more than one plausible interpretation.

Diagram 04

Key Relationships — Why does one chord change function?

This diagram uses the circle of fifths, not the chromatic note circle. Your home key is the reference. Select a comparison key: the count under each key is the number of scale tones shared with home.

C major — Home
C D E F G A B

The original tonal center.

G major — 6/7
G A B C D E F♯

Six common scale tones; only F changes to F♯.

D♭ major — 2/7
D♭ E♭ F G♭ A♭ B♭ C

The common pitch classes are C and F.

A–C–E–G can be Am7: vi7 in C, ii7 in G, or iii7 in F. Its chord shape stays the same; its function changes with the tonal center and musical context. Scale overlap does not automatically establish modulation.

MIDI input

What stays accurate when the 88-note strip is hidden?

The app still receives exact MIDI note numbers from A0 to C8, note-on and note-off events, velocity and sustain-pedal state. Chord Shapes and Interval Rays collapse octave doubling for a simpler picture; Voice Movement uses exact octave-register pitches. Chord names are theoretical interpretations and may have alternatives. This tool is intended to help you recognize relationships while playing, not force you into memorized patterns.
