# Sonatina Symphonic Orchestra sample notice

The reduced browser multisample map used by Faithful Keys was selected from the
[Sonatina Symphonic Orchestra](https://github.com/peastman/sso) by Mattias
Westlund and contributors. Faithful Keys loads the original v4.0 recordings
from an immutable GitHub revision and supplies its own Web Audio mapping,
envelopes, dynamics, and room.

license: <https://creativecommons.org/licenses/sampling+/1.0/>.
